# yt-space UI 原型 · 驗收操作手冊

> 對象：測試人員　｜　版本：mockup 原型（假資料）
> 環境：手機直式視窗（以 Pixel 7／寬約 375–412px 為基準）
> 開啟：啟動靜態伺服器後開 `home.html`（或預覽面板）
> 註：本原型為假資料，部分動作為示意（會跳提示視窗），詳見各頁說明。
> 註：**縮圖是真的**。所有片段縮圖取自 YouTube storyboard sprite（進度條預覽用的雪碧圖），
> 顯示的是該片段起點附近的真實畫面，而非影片封面。取樣間隔 5~10 秒，因此可能取到鄰近幾秒的畫面。
> 若 sprite 網址簽章過期，縮圖會自動退回封面圖 —— 這是預期中的降級行為，不算 bug。

---

## 通用：底部導覽列（每頁皆有）

- [ ] 共 5 個項目：**首頁 / 標籤 / 代辦 / 設定 / 帳號（頭像）**
- [ ] 只有 icon、無文字；目前所在頁的 icon 呈主色（靛色）
- [ ] 「代辦」右上有**紅色數字**提醒（超過顯示 `99+`）；無待辦時不顯示
- [ ] 點各項目可切換到對應頁面

---

## 一、首頁（完成度較高，重點驗收）

### 版面
- [ ] 縮圖以**月份**分組，標題格式為「YYYY年M月」（例：2026年8月）
- [ ] 每列 **3 張**縮圖，白色卡片、方角、間距小、浮於灰底之上
- [ ] 月份標題下方為**當月標籤橫條**：單行、可**左右滑動**、標籤含彩色分類 icon

### 搜尋框
- [ ] 白底、淡靛色邊框；點擊聚焦時邊框轉主色並出現一圈柔光
- [ ] 輸入關鍵字**就地即時篩選**（**不跳頁**）
- [ ] 多關鍵字以空白分隔，需**同時符合**（AND）
- [ ] 比對範圍：摘要、備註、影片標題、頻道、標籤
- [ ] 範例：輸入「潛水」→ 只剩相關片段；「米粉」→ 只剩相關片段
- [ ] 查無結果顯示「找不到符合的片段」；清空關鍵字還原全部

### 點擊行為
- [ ] 點**縮圖** → 進入該片段的**詳細頁**（跳到對應時間點）
- [ ] 點**月份標籤** → 進入**標籤頁**，並自動預選該標籤、直接顯示結果

### 時間軸（右側懸浮）
- [ ] 平時**隱藏**；**捲動或拖曳**時才在右側顯現
- [ ] 顯示**刻度**（每月一格，年份較長並標年份）
- [ ] 捲動/拖曳時浮現**半透明日期泡泡**（顯示目前年月）
- [ ] 點刻度或拖曳可快速跳到該月份；停止後自動淡出

## 二、詳細頁（大綱，待調整）

- [ ] 進度條上以半透明色塊標示**已標記的區間**
- [ ] 「我的標記」縮圖：**點擊**跳轉播放、**長按**開啟編輯視窗
- [ ] 底部「**標記此刻**」按鈕
- [ ] 編輯視窗（bottom sheet）：區間微調、備註、AI 分析、標籤、事件日期、確認
