# yt-space UI 原型 · 驗收手冊

> 對象：測試人員　｜　版本：mockup 原型（假資料）
> 環境：手機直式視窗（Pixel 7／寬約 375–412px）；另請至少開一次平板寬度與**深色模式**
> 開啟：專案根目錄執行 `pnpm mock`，再開 <http://localhost:8231/uiux-v2/login.html>
> （要先登入才進得去，直接開 home.html 會被導到登入頁；localStorage 的 key 一律 `ytspace2_`）
>
> 依據：2026-08-31 的 UI/UX 體檢報告。舊版原型（v1）已移除，
> 清單裡提到「v1 如何如何」的地方保留下來當**這樣設計的理由**，不需要再開舊版對照。

---

## 零、先看整體（不必操作）

- [ ] **底部導覽有文字**：首頁／查詢／取圖／分類／設定。v1 是五個純圖示，紅色「＋」與頭像都得用猜的。
- [ ] **紅色不見了**：v2 只有「刪除」是紅的。v1 的取圖鈕、進度條、【確定】、【套用】、【刪除】共用同一個 `#E11D48`。
- [ ] **間距與字級有尺標**：v2 只用 4/8/12/16/24/32 的間距與 6 階字級；v1 有 23 種字級、15 種圓角、13 種 gap。
- [ ] **深色模式**：把系統切成深色再開 v2，每一頁都要能讀。v1 沒有深色模式（0 條 `prefers-color-scheme`）。
- [ ] **鍵盤操作**：用 Tab 走一遍首頁，每個可點的東西都要看得到焦點框。v1 全站只有 2 條 focus 規則。
- [ ] **平板／桌機寬度**：v2 在 600px 以上加欄、900px 以上置中限寬。v1 沒有任何 `@media`。

## 一、登入（新增）

> v2 新增：整個系統要先完成 Google 第三方登入才進得去。v1 沒有登入的概念，任何頁面直接開就能用。

- [ ] **未登入時開任何一頁都會被擋**：先清掉登入狀態（設定頁按【登出】，或開發者工具刪掉
      `ytspace2_user`），再直接貼 <http://localhost:8231/uiux-v2/folders.html>，應該立刻變成登入頁。
      重點：**不該先閃一下分類頁再跳走**。閘門掛在 `<head>`，不是等頁面畫完才擋。
- [ ] **登入後回到原本要去的地方**：接上一條，按【使用 Google 帳號登入】後應該回到**分類頁**，
      不是首頁。直接開登入頁登入的才會進首頁。
- [ ] **只有一顆按鈕**：沒有帳密欄位、沒有註冊／忘記密碼。Google 登入本來就沒有這些狀態。
- [ ] **頁面上幾乎沒有字**：標記、產品名、一句話、按鈕、一行條款，就這些。
      這裡只有一條路可以走，說明文字不會改變使用者的動作，只會拖慢它。
- [ ] **Google 按鈕是中性底色＋彩色 G**：品牌識別不能改色，所以沒有套系統的紫色主按鈕。
- [ ] 按下去有**登入中**的過場（轉圈＋按鈕鎖住），不是瞬間跳頁。
- [ ] **已經登入就看不到登入頁**：登入後手動貼 <http://localhost:8231/uiux-v2/login.html>，
      應該直接被送進首頁。
- [ ] **設定頁的帳號來自登入狀態**：設定頁的名稱／Email／頭像字母跟登入的帳號一致（不是寫死在 HTML 裡）。
- [ ] **登出會真的回到登入頁**：設定頁【登出】→ 確認 → 回到登入頁，且此時再按上一頁也回不去。
- [ ] 深色模式下這一頁要能讀（尤其白底的 Google 按鈕與細字條款）。

## 二、首頁

- [ ] **欄數會跟著當月張數變**：1 張 → 整寬大圖卡；2–4 張 → 兩欄；5 張以上 → 三欄。
      對照 v1：一律三欄，於是 12 個月份群組裡有 9 個右邊三分之二是空的。
- [ ] **卡片上看得到描述**（沒有描述會顯示灰字「還沒有描述」）。v1 的首頁完全不顯示描述。
- [ ] **預設沒有時間篩選**：一進來就是完整時間軸。
      v1 預設是「本月以前」，開著、會藏掉較新的資料、還存進 localStorage。
- [ ] 右上角日曆鈕 → 選一個月份 → 出現**可清除的狀態列**「只顯示 ○年○月 以前的收藏 ✕」。
- [ ] 月份標籤**換行排列**、不再橫向捲動被切在字中間。
- [ ] 縮圖是 `<button>`，可以用 Tab 選到、Enter 打開。v1 是 `<div>`。

## 三、Lightbox

- [ ] **背景是不透明的**。v1 是 `rgba(10,10,20,0.97)`，底層的月份標題與縮圖會透出來，像沒渲染完。
- [ ] 上方顯示「第 N / 共 M 張」。v1 只有日期。
- [ ] 第一次開啟會出現一次性的「左右滑動看上一張／下一張」提示。
- [ ] 動作**分層**：一顆主要【播放這一段】＋兩顆圖示鈕（加入分類／分享），
      【編輯圖資】【刪除這張收藏】收在右上 `⋯` 裡。
      對照 v1：五顆等權重按鈕排成 3+2，刪除跟瀏覽動作並排。

## 四、取圖（改動最大）

### 全流程
- [ ] **沒有底部導覽**，左上角是【✕】。v1 三個步驟都留著導覽列。
- [ ] 進度指示**有文字**：1. 貼網址 › 2. 挑畫面 › 3. 填資料。v1 是三條沒有標示的色塊。
- [ ] 動詞統一：【下一步】→【下一步】→【完成】。v1 是【確定】→【下一步】→【完成】＋【套用】。
- [ ] 第二／三步按【✕】→ 明確詢問「保留草稿並離開／捨棄草稿」。v1 從導覽列離開時畫面上不會說草稿還在不在。

### 第一步
- [ ] 歷史紀錄是**可點的清單列**（影片圖示＋標題＋日期＋張數），點了直接進第二步。
      v1 的歷史列長得像停用的輸入框，而且點了只是把網址填進去。
- [ ] 亂打網址 → 錯誤訊息會說清楚該貼什麼格式。

### 第二步
- [ ] **一進來就已經收斂過**：頂部狀態列顯示「已收斂成 50 張候選，隱藏了 98 張相似畫面」。
      對照 v1：打開就是 148 格的候選牆，【過濾相似】預設關著。
- [ ] 按【顯示全部】→ 148 張全出現，狀態列變成【重新過濾】，可以來回切。
- [ ] 收斂強度沿用「設定 › 取圖 › 過濾相似強度」（高／中／低）。
- [ ] **每格右上角有一顆 ▶**，點了跳到那一段；長按仍然有效，但不再是唯一入口。
      v1 只能長按，鍵盤與輔助技術完全到不了。
- [ ] 工具列（全部選取／手動補圖／只看已選）**換行不截斷**。v1 橫向捲動會把「只看已選」切成「只看…」。
- [ ] 底部只有**一列**：「N 張候選 · 已選 k」＋【下一步（k 張）】。v1 底下還疊著導覽列。
- [ ] 已收藏過的格子點下去會提示「這一格已經收藏過了」，不是靜靜地沒反應。

### 第三步
- [ ] 底部收成**同一塊 dock**（抽屜＋按鈕）。v1 是抽屜＋按鈕列＋導覽列三層，可看縮圖的區域只剩四成。
- [ ] **主按鈕會變**：沒動過欄位時是【完成】；動了任一欄位就變成【套用到 N 張】。
      對照 v1：【套用】是搶眼紅鈕、【完成】是灰色外框鈕，流程終點被畫成次要動作。
- [ ] 動過欄位時，按鈕上方出現「將更新：地點、標籤　其他欄位維持各張原值」。
      這條規則在 v1 是隱形的，畫面上沒有任何說明。
- [ ] 分兩輪套用仍然正確：先勾 8 張填一組 → 再勾另外幾張填另一組 → 前一輪不受影響。
- [ ] 時間欄位下方是中性說明「預設帶入 YouTube 的日期，可以改成實際拍攝日」，
      不再是欄位標題旁邊的橘色 ⚠ 警告。
- [ ] 【完成】→ 還有沒填的會提醒但不阻擋 → 回首頁、捲到該月份、toast「已新增 N 張」。

## 五、查詢

- [ ] **條件與結果在同一頁**：選完標籤按【查詢 N 個條件】→ 同頁換成結果，左上角出現返回鍵可以改條件。
      v1 要跳到獨立的 `results.html`。
- [ ] 每個標籤 chip **帶張數**；選取後除了變色還會**多一個打勾**（不只靠顏色編碼）。
- [ ] 按鈕停用時，下方會說**為什麼**：「先選一個以上的標籤或地點」。v1 只是把按鈕變淡。
- [ ] 按鈕文字會跟著選取數量變：【查詢 3 個條件】。
- [ ] 結果列顯示「N 張 · 全部日期 · 條件 chips」。
- [ ] 從首頁的月份標籤點進來時，條件與時間會自動帶入並直接顯示結果。
- [ ] 中間那段約 400px 的空白不見了（動作列釘在導覽列上方）。

## 六、分類

- [ ] 每張資料夾卡片有**內容預覽拼貼**（最多 4 張）；空的資料夾顯示「還沒有圖片」。
      v1 只有「圖示＋名稱＋一個灰色數字」。
- [ ] 卡片右下有一顆看得見的 `⋯`（改名／刪除）；長按仍然有效。v1 只能長按。
- [ ] 沒有任何資料夾時，空狀態帶一顆【新增資料夾】。v1 是一句灰字。

## 七、詳細頁

- [ ] 播放器下方顯示**目前這一張的圖資**：描述、地點與標籤 chips、日期、影片秒數，
      以及一顆【編輯這張的圖資】。v1 這一頁完全不顯示圖資，縮圖下方是約 450px 的空白。
- [ ] 收藏縮圖右上角有**編輯鈕**；點縮圖＝跳播放，長按＝編輯（仍保留）。

## 八、設定（v1 的「帳號」頁）

- [ ] **沒有紫色漸層 header，也沒有三格統計卡**。
      v1 的三個數字（收藏片段／本月新增／來源影片）對私人收藏沒有用處，中間那格還跟首頁重複。
- [ ] 改成一行帳號列（頭像＋名稱＋Email）＋一句「目前收藏 13 張，來自 11 支影片。」
- [ ] **圖示對得上語意**：取圖＝漏斗、標籤管理＝標籤、AI 分析＝星芒、縮圖服務＝圖片。
      v1 的標籤管理用放大鏡（那是搜尋）、取圖用加號、縮圖服務跟統計卡共用同一個圖片圖示。
- [ ] 【登出】移到最底、用破壞性樣式。v1 放在漸層 header 的右上角。
- [ ] 各細項頁的說明文字不再是教學句（例如 v1 的「取圖第二步按【過濾相似】時採用這個強度。」）。

## 九、已知的取捨

- 「相似過濾」在 mock 裡是以**固定間隔**模擬（高＝每 5 張留 1、中＝每 3 張留 1、低＝每 2 張留 1），
  正式版才是畫面指紋（dHash）。v1 是以時間間距模擬，兩者都只是示意。
- 縮圖仍取自 YouTube storyboard sprite；sprite 網址簽章過期時會退回封面圖，這是預期中的降級。
- 詳細頁與分類頁在資料很少時仍會有下方留白 —— 這是資料量的結果，不是版面沒處理。
