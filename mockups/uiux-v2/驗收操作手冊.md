# yt-space UI 原型 · 驗收手冊

> 對象：測試人員　｜　版本：mockup 原型（假資料）
> 環境：手機直式視窗（Pixel 7／寬約 375–412px）；另請至少開一次平板寬度與**深色模式**
> 開啟：專案根目錄執行 `pnpm mock`，再開 <http://localhost:8231/uiux-v2/login.html>
> （要先登入才進得去，直接開 home.html 會被導到登入頁；localStorage 的 key 一律 `ytspace2_`）
>
> 依據：2026-08-31 的 UI/UX 體檢報告。

---

## 零、先看整體（不必操作）

- [ ] **底部導覽有文字**：首頁／查詢／取圖／分類／設定，五個項目都是圖示＋文字。
- [ ] **紅色只用在破壞性動作**：整個原型裡只有「刪除」是紅的，主要動作一律是主色。
- [ ] **間距與字級有尺標**：間距只用 4/8/12/16/24/32，字級只有 6 階。
- [ ] **深色模式**：把系統切成深色再走一遍，每一頁都要能讀。
- [ ] **鍵盤操作**：用 Tab 走一遍首頁，每個可點的東西都要看得到焦點框。
- [ ] **平板／桌機寬度**：600px 以上會加欄、900px 以上置中限寬。

---

## 一、登入

> 整個系統要先完成 Google 第三方登入才進得去。

- [ ] **未登入時開任何一頁都會被擋**：先清掉登入狀態（設定頁按【登出】，或開發者工具刪掉
      `ytspace2_user`），再直接貼 <http://localhost:8231/uiux-v2/folders.html>，應該立刻變成登入頁。
      重點：**不該先閃一下分類頁再跳走**。閘門掛在 `<head>`，不是等頁面畫完才擋。
- [ ] **登入後回到原本要去的地方**：接上一條，按【使用 Google 帳號登入】後應該回到**分類頁**，
      不是首頁。直接開登入頁登入的才會進首頁。
- [ ] **只有一顆按鈕**：沒有帳密欄位、沒有註冊／忘記密碼。Google 登入本來就沒有這些狀態。
- [ ] **頁面上幾乎沒有字**：標記、產品名、一句話、按鈕、一行條款，就這些。
      這裡只有一條路可以走，說明文字不會改變使用者的動作，只會拖慢它。
- [ ] **Google 按鈕是中性底色＋彩色 G**：品牌識別不能改色，所以沒有套系統的紫色主按鈕。
- [ ] 按下去有**登入中**的過場（轉圈＋按鈕鎖住），不是瞬間跳頁。
- [ ] **已經登入就看不到登入頁**：登入後手動貼 <http://localhost:8231/uiux-v2/login.html>，
      應該直接被送進首頁。
- [ ] **設定頁的帳號來自登入狀態**：設定頁的名稱／Email／頭像字母跟登入的帳號一致（不是寫死在 HTML 裡）。
- [ ] **登出會真的回到登入頁**：設定頁【登出】→ 確認 → 回到登入頁，且此時再按上一頁也回不去。
- [ ] 深色模式下這一頁要能讀（尤其白底的 Google 按鈕與細字條款）。

## 二、首頁

- [ ] **欄數會跟著當月張數變**：1 張 → 整寬大圖卡；2–4 張 → 兩欄；5 張以上 → 三欄。
      張數少的月份不該留下大片空白。
- [ ] **卡片上看得到描述**（沒有描述會顯示灰字「還沒有描述」）。
- [ ] **預設沒有時間篩選**：一進來就是完整時間軸，不會有預設條件藏掉較新的資料。
- [ ] 右上角日曆鈕 → 選一個月份 → 出現**可清除的狀態列**「只顯示 ○年○月 以前的收藏 ✕」。
- [ ] 月份標籤**換行排列**，不會橫向捲動被切在字中間。
- [ ] 縮圖是 `<button>`，可以用 Tab 選到、Enter 打開。

## 三、Lightbox

- [ ] **背景是不透明的**，底層的月份標題與縮圖不會透出來。
- [ ] 上方顯示「第 N / 共 M 張」。
- [ ] 第一次開啟會出現一次性的「左右滑動看上一張／下一張」提示。
- [ ] 動作**分層**：一顆主要【播放這一段】＋兩顆圖示鈕（加入分類／分享），
      【編輯圖資】【刪除這張收藏】收在右上 `⋯` 裡 —— 刪除不該跟瀏覽動作並排。

## 四、取圖

### 全流程
- [ ] **沒有底部導覽**，左上角是【✕】。三個步驟都一樣。
- [ ] 進度指示**有文字**：1. 貼網址 › 2. 挑畫面 › 3. 填資料。
- [ ] 動詞統一：【下一步】→【下一步】→【完成】。
- [ ] 第二／三步按【✕】→ 明確詢問「保留草稿並離開／捨棄草稿」，畫面上要說得出草稿還在不在。

### 第一步
- [ ] 歷史紀錄是**可點的清單列**（影片圖示＋標題＋日期＋張數），點了直接進第二步，
      不是只把網址填回輸入框。
- [ ] 亂打網址 → 錯誤訊息會說清楚該貼什麼格式。

### 第二步
- [ ] **一進來就已經收斂過**：頂部狀態列顯示「已收斂成 50 張候選，隱藏了 98 張相似畫面」，
      而不是打開就是 148 格的候選牆。
- [ ] 按【顯示全部】→ 148 張全出現，狀態列變成【重新過濾】，可以來回切。
- [ ] 收斂強度沿用「設定 › 取圖 › 過濾相似強度」（高／中／低）。
- [ ] **每格右上角有一顆 ▶**，點了跳到那一段；長按仍然有效，但不是唯一入口
      —— 鍵盤與輔助技術也要到得了。
- [ ] 工具列（全部選取／手動補圖／只看已選）**換行不截斷**，文字不會被切掉。
- [ ] 底部只有**一列**：「N 張候選 · 已選 k」＋【下一步（k 張）】，底下不再疊導覽列。
- [ ] 已收藏過的格子點下去會提示「這一格已經收藏過了」，不是靜靜地沒反應。

### 第三步
- [ ] 底部收成**同一塊 dock**（抽屜＋按鈕），不是抽屜／按鈕列／導覽列三層把縮圖區壓到剩四成。
- [ ] **主按鈕會變**：沒動過欄位時是【完成】；動了任一欄位就變成【套用到 N 張】。
      流程終點（【完成】）永遠是最搶眼的那一顆。
- [ ] 動過欄位時，按鈕上方出現「將更新：地點、標籤　其他欄位維持各張原值」
      —— 這條規則要看得見，不能只存在於腦袋裡。
- [ ] 分兩輪套用仍然正確：先勾 8 張填一組 → 再勾另外幾張填另一組 → 前一輪不受影響。
- [ ] 時間欄位下方是中性說明「預設帶入 YouTube 的日期，可以改成實際拍攝日」，
      不是欄位標題旁邊的橘色 ⚠ 警告。
- [ ] 【完成】→ 還有沒填的會提醒但不阻擋 → 回首頁、捲到該月份、toast「已新增 N 張」。

## 五、查詢

- [ ] **條件與結果在同一頁**：選完標籤按【查詢 N 個條件】→ 同頁換成結果，左上角出現返回鍵可以改條件，
      不會跳到另一個獨立頁面。
- [ ] 每個標籤 chip **帶張數**；選取後除了變色還會**多一個打勾**（不只靠顏色編碼）。
- [ ] 按鈕停用時，下方會說**為什麼**：「先選一個以上的標籤或地點」，不是只把按鈕變淡。
- [ ] 按鈕文字會跟著選取數量變：【查詢 3 個條件】。
- [ ] 結果列顯示「N 張 · 全部日期 · 條件 chips」。
- [ ] 從首頁的月份標籤點進來時，條件與時間會自動帶入並直接顯示結果。
- [ ] 動作列釘在導覽列上方，中間不會出現大段空白。

## 六、分類

- [ ] 每張資料夾卡片有**內容預覽拼貼**（最多 4 張）；空的資料夾顯示「還沒有圖片」。
- [ ] 卡片右下有一顆看得見的 `⋯`（改名／刪除）；長按仍然有效，但不是唯一入口。
- [ ] 沒有任何資料夾時，空狀態帶一顆【新增資料夾】，不是只有一句灰字。

## 七、詳細頁

- [ ] 播放器下方顯示**目前這一張的圖資**：描述、地點與標籤 chips、日期、影片秒數，
      以及一顆【編輯這張的圖資】—— 縮圖下方不該是大片空白。
- [ ] 收藏縮圖右上角有**編輯鈕**；點縮圖＝跳播放，長按＝編輯（仍保留）。

## 八、設定

- [ ] **沒有紫色漸層 header，也沒有三格統計卡**。
- [ ] 改成一行帳號列（頭像＋名稱＋Email）＋一句「目前收藏 13 張，來自 11 支影片。」
- [ ] **圖示對得上語意**：取圖＝漏斗、標籤管理＝標籤、AI 分析＝星芒、縮圖服務＝圖片。
      同一個圖示不會出現在兩個不同語意的地方。
- [ ] 【登出】移到最底、用破壞性樣式。
- [ ] 各細項頁的說明文字是**這個設定會影響什麼**，不是操作教學句。

## 九、已知的取捨

- 「相似過濾」在 mock 裡是以**固定間隔**模擬（高＝每 5 張留 1、中＝每 3 張留 1、低＝每 2 張留 1），
  正式版才是畫面指紋（dHash）；這裡只是示意。
- 縮圖仍取自 YouTube storyboard sprite；sprite 網址簽章過期時會退回封面圖，這是預期中的降級。
- 詳細頁與分類頁在資料很少時仍會有下方留白 —— 這是資料量的結果，不是版面沒處理。
