# yt-space UI 原型 · 驗收操作手冊（Shot 版）

> 對象：測試人員　｜　版本：mockup 原型（假資料）
> 環境：手機直式視窗（以 Pixel 7／寬約 375–412px 為基準）
> 開啟：在專案根目錄執行 `pnpm mock`，開 <http://localhost:8231/uiux/home.html>
> 對應規格：`docs/superpowers/specs/2026-08-27-yt-space-shot-design.md`
> 註：本原型為假資料，儲存動作只活在當前分頁（重新整理即還原）；部分動作為示意。
> 註：**縮圖是真的**。取自 YouTube storyboard sprite，取樣間隔 5~10 秒。
> 若 sprite 網址簽章過期，縮圖會退回封面圖 —— 這是預期中的降級行為，不算 bug。

---

## 通用：底部導覽列（每頁皆有）

- [ ] 共 5 格等寬：**首頁 / 查詢 / 取圖 / 分類 / 帳號（頭像）**
- [ ] 【取圖】與其他四格同大小，**只用紅色突出**、不凸出
- [ ] 舊版的「代辦」「設定」已移除（設定併入帳號頁）

---

## 一、首頁

- [ ] 縮圖依**年月**分組；頂列可選「某月以前」；右側有懸浮時間軸
- [ ] **點縮圖 → 開 Lightbox 全屏檢視**（不再直接跳詳細頁）
- [ ] 取圖完成導回時：自動跳到新圖所在月份，頂部 toast「已新增 N 張」

## 二、Lightbox（首頁／查詢結果／資料夾內容共用）

- [ ] 全屏大圖（L3 解析度放大，稍軟屬正常）；上方顯示「第 N / 共幾張」
- [ ] **左右滑動**（或點兩側箭頭）＝上一張／下一張，範圍＝目前所在的清單
- [ ] 圖下方顯示：描述（沒有則灰字提示）、地點＋標籤 chips、日期・時間・影片名
- [ ] 五顆按鈕：
  - [ ] 【影片播放】→ 詳細頁，播放器跳到該秒
  - [ ] 【加入分類】→ 資料夾樹勾選（可勾多個、可就地新增資料夾）
  - [ ] 【分享】→ 系統分享面板（不支援時複製 youtu.be 連結＋秒數）
  - [ ] 【編輯】→ bottom sheet 就地編輯描述／地點／標籤／時間
  - [ ] 【刪除】→ 確認後刪除，自動跳下一張

## 三、取圖精靈（點導覽列中間【取圖】）

### 第一步：輸入網址
- [ ] 貼網址或 videoId；示範影片連結點了自動帶入
- [ ] 亂打 → 就地顯示「無法解析」；非示範影片 → 「抓不到」訊息
- [ ] 頂部有四段進度條，目前步驟以前為紅色

### 第二步：挑圖
- [ ] 上方假播放器（sb 畫面＋時間拉桿）釘住不隨捲動消失
- [ ] 縮圖牆每列 3 張、右下角時間；首次進入顯示一次性操作提示
- [ ] **點一下＝勾選**（紅框＋紅點）；**長按＝播放器跳到該秒**（藍框標示）
- [ ] 已收藏過的格子顯示「已收藏」且不可勾（示範影片 Ea8ICLXTDaU 有 3 格）
- [ ] 【全部選取】：全選／全不選切換（不含已收藏）
- [ ] 【過濾相似】＋強度（高／中／低）：被濾掉的變半透明打叉，出現「已過濾 N 張　復原」
  - [ ] 按【復原】完全還原；單獨點回某張也可以
  - [ ] mock 以時間間距模擬相似度，正式版為畫面指紋（dHash）
- [ ] 【手動補圖】：時間自動帶入播放器位置、可選自己的圖，加入後帶「手動」標
- [ ] 【只看已選】：篩選顯示
- [ ] 底部固定列：「共 N 張 · 已選 k」＋【下一步】（0 張時停用）

### 第三步：定義圖資
- [ ] 快捷列：全選／全不選／反選／未填的
- [ ] 抽屜標題永遠是「套用到已選的 N 張」；勾 1 張時顯示該張現有值
- [ ] 多張且欄位值不一致 → 顯示紫色斜體「〈多個值〉」
- [ ] **只有動過的欄位會被套用**：全選後只改標籤 → 各張地點、描述不變
- [ ] 已套用的格子帶**綠點**；底部顯示「N 張 · k 已完成」
- [ ] 分兩輪套用：先勾 8 張填一組 → 再勾另外幾張填另一組 → 前一輪不受影響
- [ ] 【完成】：還有未填的會提醒但不阻擋 → 回首頁、跳到該月份、toast

### 草稿
- [ ] 第二步勾了幾張後直接關頁 → 再點【取圖】出現「上次…做到第 N 步，要繼續嗎？」
- [ ] 【繼續】回到原步驟與原選擇；【重新開始】清空

## 四、查詢

- [ ] 標籤查詢／文字查詢兩種方式（沿用前版）
- [ ] 結果縮圖點擊 → **Lightbox**（不再直接跳詳細頁）
- [ ] （正式版將把「地點」併入標籤輪播顯示，mock 尚未實作此項）

## 五、分類（資料夾）

- [ ] 樹狀清單（子層縮排）；計數**含子孫層**（「旅遊」= 自身 0 + 子層 7）
- [ ] 【新增資料夾】建根層；**長按**資料夾 → 改名／新增子資料夾／刪除
- [ ] 第 5 層不能再建子層（選項停用並註明）
- [ ] 刪除資料夾：確認框明示「圖本身不會被刪」；刪後圖仍在首頁
- [ ] 點資料夾 → 內容頁：麵包屑、子資料夾在上、本層圖片網格在下
- [ ] 內容頁點圖 → Lightbox（滑動範圍＝該資料夾的圖）

## 六、詳細頁

- [ ] 標題區塊改為「**這支影片的收藏**」；底部**沒有**【標記此刻】按鈕了
- [ ] Lightbox【影片播放】進來時，播放器已跳到該秒
- [ ] 收藏縮圖：點＝跳播放、**長按＝就地編輯**（描述／地點／標籤／時間）
- [ ] 右上 `⋯` → 影片管理選單：
  - [ ] 【繼續取這支的圖】→ 精靈第二步，已收藏格子鎖定
  - [ ] 【批次編輯圖資】→ 精靈第三步同一介面，載入這支影片的所有收藏
  - [ ] 【刪除整支收藏】→ 確認框顯示張數 → 刪後回首頁
